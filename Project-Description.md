# Rehab — опис проєкту

Rehab допомагає вести календар тверезості, бачити особистий прогрес і отримувати підтримку ментора. Це навчальний вебзастосунок; медичні консультації, платежі та інтеграції з носимими пристроями не входять до його обсягу.

## Можливості

- Реєстрація, вхід, вихід та приватний профіль із фото, зміною пароля й налаштуваннями.
- Календар sober/relapse, деталі дня, редагування статусу й тригера протягом 48 годин включно.
- Поточна та найдовша серії, статистика за період і фіксовані етапи 7, 30, 90, 180, 365 днів без створення власних цілей.
- Добровільне менторство за постійним кодом: один активний ментор для підопічного, кілька підопічних для ментора. Доступ перевіряється за активним зв’язком.
- Приватні повідомлення про перший зрив, один коментар підтримки на таке повідомлення та скарги з доказом. Повного чату немає.
- Адміністрування скарг і агрегована аналітика. Схвалення скарги закриває конкретну пару менторства, зберігаючи доступ до власного акаунта.
- Нагадування після 20:00 Europe/Kyiv за відсутності явного запису; пошта лише за згодою та після налаштування Gmail.
- Чотири стилі автоматичних текстів; особисті коментарі залишаються незмінними.

## Технології та розгортання

Expo Web / React Native / TypeScript, FastAPI / Python 3.12, SQLAlchemy / psycopg / Alembic і PostgreSQL. Frontend — Render Static Site, API — Render Free, онлайн-БД — Neon Free. Локальні dev/test бази відокремлені; дані та фото зберігаються в PostgreSQL.

Запуск описано в [setup_and_run.md](setup_and_run.md), вимоги — у [requirements.md](docs/requirements/requirements.md), приймання — у [test-plan.md](docs/validation/test-plan.md). Мобільне приймання проводиться на iPhone у Safari; підтримку Android не позначено перевіреною.
