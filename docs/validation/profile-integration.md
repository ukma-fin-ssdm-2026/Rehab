## Запуск тестів

> **Важливо:** використовувати лише окрему тестову PostgreSQL, не робочу Neon. `DATABASE_URL` і `TEST_DATABASE_URL` мають вказувати на різні бази, а назва тестової бази — закінчуватися на `_test`. Тести можуть очищати її дані.

З кореня проєкту:

```powershell
python -m pip install -r requirements.txt
python -m alembic -x test_db=true upgrade head
python -m pytest -q
```
