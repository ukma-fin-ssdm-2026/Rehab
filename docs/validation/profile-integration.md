# Перевірка профілю — КТ-Б / КТ-В

## Що перевірено

На коміті `69b4c36` [GitHub CI](https://github.com/ukma-fin-ssdm-2026/Rehab/actions/runs/41213545706) успішний: тести backend на ізольованій PostgreSQL з міграціями Alembic, frontend-збірка та перевірки. Покриття backend на попередньому перевіреному прогоні — **94%**. Code Quality і RTM теж пройшли.

Автоматичні тести перевіряють:
- Доступ лише до власного профілю та збереження імені, нікнейма й налаштувань.
- Зміну пароля, відмову за неправильного пароля та відкликання старих JWT.
- Приватність аватара, обмеження розміру, заміну, видалення та синтетичний HEIC.

## Як повторити тести

**Тільки на окремій тестовій PostgreSQL**, не на робочій Neon. `DATABASE_URL` і `TEST_DATABASE_URL` мають вказувати на різні БД; назва тестової закінчується на `_test`. Тести очищають тестові дані.

Із кореня репозиторію:

```powershell
python -m pip install -r requirements.txt
python -m alembic -x test_db=true upgrade head
python -m pytest -q
```
