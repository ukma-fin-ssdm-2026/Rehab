# КТ-2: головна, статистика й фіксовані цілі

Основа: develop 0a00781, включно з календарем PR 192 та виправленням цілей PR 193. Марія працює у maria-kt2. Погоджені етапи 7 і 30 днів замінюють особисті CRUD-цілі з початкового ТЗ; форма створення не потрібна. Legacy-таблиця goals не використовується для прогресу.

## Реалізація

Три екрани читають спільний контракт GET /statistics через apiRequest. Успішні create/PATCH календаря сповіщають активні екрани. Повернення фокуса екрана або вкладки Safari запускає новий запит. Старі відповіді та помилки після зміни періоду, blur або акаунта ігноруються. Дані попереднього акаунта й періоду не відображаються. Помилка показує повтор запиту. Статистика має week/month/year/all; поточна й найкраща серії завжди за всю історію.

Виконання 7/30 — за найдовшою серією. Звичайний новий зрив зберігає історичний бейдж; корекція історії перераховує його. Невиконаний прогрес обмежений етапом і поточною серією. Дні без записів після початку відстеження враховуються тверезими; інтерфейс пояснює це.

## Спільна онлайн-перевірка — очікує розгортання

На комп’ютері й iPhone/Safari зафіксувати публічні URL, commit, модель телефона та iOS. Створити sober-запис, перейти на головну, цілі й статистику: цифри відповідають календарю без reload. Створити relapse та змінити його назад на sober в межах 48 годин: усі три екрани відображають нові серії та етапи. Для демонстраційної історії перевірити перехід 6→7, 29→30, історичну відзнаку після нового зриву й втрату відзнаки після корекції відповідної історії. Перемикати періоди за повільної мережі; повернути Safari із фону; симулювати помилку мережі й повторити. Увійти другим користувачем: дані першого відсутні. Прямі посилання та reload перевіряються разом із календарною й auth-частинами. Android не позначається перевіреним.

Автоматичні результати наведені нижче після фактичного запуску. Повну онлайн-готовність та успішну КТ-2 підтверджує команда після спільного проходження, а не цей документ.


## Фактичні автоматичні перевірки

255 серверних тестів пройшли на локальній PostgreSQL 16 через окремий Compose postgres-test (pytest -q, 194.52 s). Тестова схема створена Alembic; онлайн-БД не використовувалась. Одне попередження Starlette про майбутню зміну тестового HTTP-клієнта.

19 клієнтських тестів пройшли, включно з lifecycle, browser visibility, ізоляцією акаунта та затриманими відповідями. TypeScript пройшов. Black backend, flake8 backend та перевірка traceability пройшли. Новий серверний тест відформатовано Black. Перед перевірками встановлено 815 залежностей через npm ci без зміни lock-файлу.

Незалежний read-only огляд важливих дефектів не знайшов; запропоноване покриття lifecycle додано та перевірено. Реальний iPhone та онлайн-наскрізний сценарій ще мають пройти командну перевірку після публікації frontend.

ESLint завершився з кодом 0: 0 помилок, 2 попередження react-hooks/set-state-in-effect у незмінених admin/analytics.tsx і admin/users.tsx.

Production web export успішний: Expo зібрав 924 модулі та створив frontend/dist; команда npm run export:web завершилася з кодом 0. Онлайн-розгортання цією локальною перевіркою не підтверджене.
