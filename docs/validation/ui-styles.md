# Навігація, фото і стилі повідомлень

## Поведінка

- На внутрішніх екранах є спільна кнопка «Назад». Вона використовує історію застосунку; без історії повертає користувача на `/home`, адміністратора — на `/admin/complaints`. На головних екранах, вході, реєстрації та onboarding кнопка прихована.
- Фото з галереї: JPEG/JPG, PNG, WebP, HEIC/HEIF та AVIF. Клієнт розпізнає сигнатуру файлу, якщо браузер не передає коректний MIME або розширення. Сервер декодує вміст, перевіряє ліміти 5 МіБ / 64 Мп і нормалізує до JPEG ≤512 px / 256 KiB. Пошкоджений файл не стає допустимим через перейменування.
- Формальний стиль залишається типовим. Гумористичний містить погоджену ненормативну лексику: перед його вибором є попередження, підтвердження та скасування. Суворий — різкий, без мату. Дзен — короткі цитати з атрибуцією та контекстні підказки.
- Чотири варіанти автоматичних текстів чергуються після кожного успішного нового входу та з початком нового дня `Europe/Kyiv`. Відновлення сесії й оновлення сторінки зберігають варіант. Лічильник містить лише номер варіанта, дату та ID власника, без JWT чи особистих записів. Коли сховище браузера недоступне, використовується пам’ять поточної сторінки.
- Автоматичні повідомлення в inbox використовують поточний стиль і варіант через необов’язковий параметр `variant=0..3`; особисті коментарі ментора не переписуються. Поштові нагадування чергуються за київською датою job, незалежно від входів у браузері.
- На головній кнопка повідомлень показує конверт і кількість; назва для читача екрана збережена. Пояснення етапів і автоматичного тверезого дня на екрані цілей розташовані після картки «Пам’ятай».

## Джерела цитат

Короткі українські переклади підготовлені для інтерфейсу за перекладами Джеймса Легґа:

- [Лао-цзи, «Дао де цзін», розділи 8, 63, 64](https://www.gutenberg.org/files/216/216-h/216-h.htm): вода без суперництва, велике починається з малого, подорож починається з кроку.
- [Конфуцій, «Лунь юй», 1.8](https://www.gutenberg.org/cache/epub/3330/pg3330-images.html): не боятися виправляти власні помилки.

## Перевірки

Автоматизовані перевірки охоплюють підтвердження/скасування стилю, чергування при вході та київській півночі, відновлення сесії, ізоляцію акаунтів, контракти inbox, незмінність коментарів, декодування AVIF та інші формати, навігаційні fallback.

31.10.2026: пройшли 463 серверні тести (покриття 93%), 90 клієнтських тестів, TypeScript, lint, web export, Black, Flake8, Bandit і перевірка простежуваності вимог. Незалежне фінальне review не виявило суттєвих регресій.

Локально в браузері з шириною 430 px перевірено попередження, скасування і підтвердження стилю, його збереження, зміну фраз після повторного входу та кнопку повернення з профілю. Пояснення цілей розташовані після «Пам’ятай»; горизонтального переповнення сторінки немає. Це не є перевіркою на справжньому iPhone. Після розгортання потрібно повторити вибір фото з галереї Safari, навігацію і тексти на iPhone 16 Pro Max / iOS 18.3.2. Реальну доставку пошти Render цим набором змін не підтверджено.
