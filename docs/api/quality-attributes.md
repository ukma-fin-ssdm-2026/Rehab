## Цілісність і помилки

UNIQUE(user_id,date) забороняє дубль календарного запису. Календар, перерахунок та подія зриву атомарні. Один коментар на повідомлення, одне нагадування на адресата й дату, одна доставка на notification. Невизначені доставки не повторюються автоматично.

Редагування дозволене до 48 годин включно від created_at; пізніше — 403 EDIT_WINDOW_EXPIRED. Це бізнес-правило FR-008, а не критерій продуктивності. Помилки мають code/message/details. Джерело точних схем — [OpenAPI](openapi-generated.yaml).

Після збереження календаря пов’язані екрани оновлюються без ручного reload. Відповідь попереднього акаунта/періоду не замінює актуальні дані; помилка має окремий стан і повтор. Прямі URL та reload перевіряються разом зі SPA rewrite. Автоматичні перевірки не замінюють приймання публічної версії.

## Вимірювані властивості реалізованих операцій

| Властивість | Ціль / умова провалу | Конкретна перевірка |
|---|---|---|
| Вікно редагування FR-008 | 100% PATCH до 48 год включно дозволені власнику за валідного тіла; 100% пізніших — 403. Будь-який обхід — провал | test_postgres_entries.py::test_exact_edit_window_and_original_creation_time |
| Унікальність дати | 0 дублів user/date; повторний POST — 409. Два рядки — провал | test_calendar_postgres_api.py::test_duplicate_is_409_and_does_not_remove_original |
| Ізоляція повідомлень | 0 повернень чужого inbox/detail; read ідемпотентний | test_notifications.py::test_inbox_is_private_paginated_and_read_is_idempotent |
| Атомарність | 0 часткових календарних записів/подій після помилки | test_calendar_message_flow.py::test_event_failure_rolls_back_calendar_progress_and_notification |
| Формат помилок | 100% перевірених 403/404/409/422 містять code/message/details; відсутнє поле — провал | test_calendar_postgres_api.py, test_calendar.py; схема ErrorResponse |

Компроміси: серверні перевірки й блокування збільшують роботу БД, але забезпечують право доступу та цілісність; пагінація обмежує відповідь, потребуючи повторного запиту; unknown у пошті уникає повторного листа ціною ручного розбору невизначеної доставки. Висновок щодо продуктивності потребує вимірювання, а не припущення.
