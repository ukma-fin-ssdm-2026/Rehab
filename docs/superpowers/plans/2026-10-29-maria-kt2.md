# КТ-2 Марії: узгоджений прогрес

Мета: головна, цілі 7/30 та статистика читають реальний API і оновлюються після календарних змін без reload. Основа — develop після PR 192/193, Expo 57, спільний apiRequest, незмінні правила серій і 48 годин. Особисті цілі замінені погодженими фіксованими етапами. Онлайн-перевірка — разом із командою, лише iPhone/Safari для телефона.

- [x] Спільний контракт statistics та механізм останнього актуального запиту: тест затриманих відповідей, скасування після blur та помилок.
- [x] Повідомлення про успішні create/PATCH календаря; помилка не повідомляє про зміну. Перевірити підписку та відписку.
- [x] Спільний hook для трьох екранів: focus, повернення вкладки браузера, зміна періоду, очищення при зміні акаунта; повтор запиту після помилки.
- [x] Головна та цілі показують однаковий активний етап, обмежений прогрес і історичні відзнаки. Статистика підтримує all/week/month/year та пояснює дні без записів.
- [x] Регресійні frontend/серверні тести, lint, TypeScript, web export, документація КТ-2 й чесний перелік ручних онлайн-перевірок.
- [ ] Короткі українські коміти, push maria-kt2, текст нового PR погодити з Марією перед створенням.

Ризики перевірки: повільна стара відповідь, перехід між користувачами, відмова сервера, корекція історії з втратою відзнаки, повернення Safari із фону. Production-БД для тестів не використовувати.

Підсумок: 255 серверних та 19 клієнтських тестів пройшли; TypeScript, ESLint (0 помилок, 2 попередження в admin), Black, flake8, traceability та web export успішні. Короткі коміти підготовлено. Новий PR і його текст очікують погодження Марії; спільна онлайн-перевірка очікує публікації.
