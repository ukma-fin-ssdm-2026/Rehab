# Рекомендації щодо якості тестів — Lab 06

## Поточний стан

У наборі тестів проєкту Rehab успішно проходять 91 тест. Загальне покриття коду становить 99% (320 операторів, 3 непокриті). Модуль `backend/app/services/statistics.py` покритий на 100%.

## Рекомендації

1. **Зберігати перевірки граничних випадків.** Тестувати некоректні періоди, майбутні дати, порожні дані та недозволені операції.
2. **Підтримувати ізольованість тестів.** Використовувати фікстури й заглушки, щоб результати не залежали від стану попередніх тестів або зовнішніх сервісів.
3. **Перевірити три непокриті оператори.** Рядки `backend/app/main.py:86`, `backend/app/models.py:86` та `backend/app/routers/calendar.py:108` варто проаналізувати й додати тести, якщо ці гілки відповідають важливій поведінці.
4. **Не максимізувати покриття заради відсотка.** Пріоритет — перевірка значущої поведінки, обробки помилок і регресій.
5. **Запускати тести в CI.** Автоматично виконувати набір тестів і формувати звіт покриття під час перевірки змін.

## Висновок

Поточне покриття високе, а всі 91 тест проходять. Подальші покращення мають зосереджуватися на значущості тестів, граничних випадках і перевірці непокритих операторів.
