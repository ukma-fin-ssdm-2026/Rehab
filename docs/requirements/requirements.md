## Нефункціональні вимоги (NFR)
PERF-001 (Продуктивність): 95-й процентиль часу відповіді API для оновлення календаря та завантаження статистики не повинен перевищувати 500 мс при навантаженні 100 одночасних користувачів.

SEC-001 (Безпека): Усі запити до панелі Адміністратора, модерації скарг та статистики інших користувачів повинні перевірятися на наявність відповідних JWT-токенів із ролями admin або mentor.

SEC-002 (Безпека): Паролі користувачів повинні зберігатися в базі даних виключно у вигляді криптографічних хешів (наприклад, bcrypt).

REL-001 (Надійність): Доступність системи (Uptime) повинна становити не менше 99,5% часу на місяць, щоб користувачі не втрачали можливість зробити щоденну відмітку.

USAB-001 (Зручність використання): Процес створення нової цілі (US-003) повинен займати у користувача не більше 3 кліків від головного екрана.
