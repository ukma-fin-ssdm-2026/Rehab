## Бонус №4 — пошук нестабільних тестів

Підготовлено окремий ручний workflow Lab10 Flaky Test Check: один job, один раннер, п'ять послідовних повних повторів backend і frontend на одному SHA. Порівнюються результати кожного тесту; звіти про нестабільність і стабільні падіння розділено, неповний експеримент не подається як успішний.

Докладна реалізація і локальна перевірка: [bonus-flaky-tests.md](./bonus-flaky-tests.md).

За період 27.10–16.11.2026 у CI Pipeline на main немає успішних повторних спроб із attempt>1 (0 із 54 записів); [список і джерело](./evidence/bonus4-reruns.json).

**Стан:** реалізацію підготовлено; для завершення потрібні погоджене злиття, реальний manual run, його URL/SHA/результати та пояснення у Loom. Заповнені вигаданими значеннями поля не додаються. Якщо нестабільність знайдено, потрібні виправлення або карантин з issue і причиною.

Codex використано для форматування й упорядкування наданих даних та технічної допомоги з погодженим workflow і перевірками за завданням користувачки.
