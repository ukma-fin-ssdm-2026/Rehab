## Час у черзі та час виконання окремо

Для кожного job від GitHub API взято `created_at`, `started_at`, `completed_at`. Очікування = `started_at - created_at`, виконання = `completed_at - started_at`.

| Показник | Медіана | Вимірювання |
| --- | ---: | ---: |

Обидва показники обчислені на рівні **окремих CI jobs**: одночасні job не підсумовуються. У незапущеного CI #43096573477 jobs немає.

## Зіставлення з ручним підрахунком

Автоматичний і ручний результати **збігаються за всіма чотирма метриками**: частота 2,52 CI/день; медіанний Lead Time 1,44 год; частка невдалих завершених CI 0%; час відновлення не визначається. Середнє Lead Time також збігається — 15,91 год. Для кінця успішного CI використано останній `jobs.completed_at`: у вибірці різниця з `run.updated_at` не перевищує 1 с і не впливає на підсумкові округлені значення.

**Додаткові дані автоматизації** — медіани очікування й виконання окремих jobs (21,00 с та 106,50 с). У [первинній таблиці ролі №1](https://github.com/ukma-fin-ssdm-2026/Rehab/blob/main/docs/ci-cd/metrics-raw.md) обчислені інші показники — для **цілого CI-запуску**: медіана черги **7 с** і виконання **113 с**. Це різні сукупності спостережень (84 jobs проти 53 завершених запусків), а не розбіжність формул.

## Скрипт, запуск і докази

- [Скрипт підрахунку](../../scripts/dora_metrics.py) читає GitHub REST API із пагінацією, обчислює 4 метрики, розділяє чергу й виконання та створює Markdown-результат.
- [API-знімок](./evidence/dora-auto-api-snapshot.json) містить записи 54 запусків CI, 54 злитих PR, час першого коміту кожного PR та timestamps для всіх доступних CI jobs.
- [Ручний підрахунок](./dora-metrics.md) і [первинна таблиця ролі №1](https://github.com/ukma-fin-ssdm-2026/Rehab/blob/main/docs/ci-cd/metrics-raw.md) дозволяють перевірити результат незалежно. [README доказів ролі №1](https://github.com/ukma-fin-ssdm-2026/Rehab/blob/main/docs/ci-cd/evidence/README.md) містить походження даних та зіставлення часових меж.

Запуск із кореня репозиторію через GitHub API після `gh auth login` або за наявності `GH_TOKEN`:

```bash
python scripts/dora_metrics.py --repo ukma-fin-ssdm-2026/Rehab --start 2026-10-27 --end 2026-11-16 --output docs/ci-cd/dora-auto-results.md
```

Відтворення підрахунку на зафіксованих API-даних без мережі:

```bash
python scripts/dora_metrics.py --snapshot docs/ci-cd/evidence/dora-auto-api-snapshot.json --output docs/ci-cd/dora-auto-results.md
```

Скрипт не запускає GitHub Actions і не займає раннер. Метрики є **навчальними CI-проксі**, а не свідченнями production deploy або production incident. Підрахунок і таблиці підготовлено з використанням інструментів автоматизації; дати та статуси походять з GitHub API.
