## Як оновити докази за потреби

Для нового незалежного експорту авторизований учасник може використати GitHub REST API:

- `GET /repos/ukma-fin-ssdm-2026/Rehab/actions/runs?branch=main&event=push&created=2026-10-27..2026-11-16&per_page=100` — пройти всі сторінки й відфільтрувати workflow `CI Pipeline`.
- `GET /repos/ukma-fin-ssdm-2026/Rehab/actions/runs/{run_id}/jobs?filter=latest&per_page=100` — пройти всі сторінки jobs.
- `GET /repos/ukma-fin-ssdm-2026/Rehab/pulls/{number}/commits?per_page=100` — пройти всі сторінки й визначити найраніший authored timestamp.

Незалежний запит списку запусків через workflow endpoint виконано й збережено у main-ci-runs-api.json; наведені тут запити для повторного збору всіх jobs і комітів PR не виконувалися. Якщо стан queued змінився, збережіть новий знімок окремо й поясніть відмінність від PR #268.
